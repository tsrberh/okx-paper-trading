## 模拟盘能力速览：能练什么，不能做什么

官方对模拟盘的定义是「与真实的交易环境一样、使用虚拟资金在虚拟市场内进行的交易」，并说明「一般情况下，模拟交易含有实盘的所有交易模式，在功能上也与实盘保持一致」。这句话信息量不小，但真正影响你判断的是下面这张表里的分项。

| 能力项 | 是否支持 | 说明 |
| --- | --- | --- |
| 现货 | 支持 | 覆盖常用币对和部分高热度币对，总数少于实盘 |
| 永续合约 | 支持 | App 与网页端都有，可练 BTCUSDT 永续开多开空 |
| 期权 | 支持 | 官方帮助页把期权列为模拟盘可交易产品 |
| 策略交易 | 支持 | 网格、马丁格尔、定投等，具体清单见下文说明 |
| 子账户 | 不支持 | 官方明确：子账户功能只适用于真实账户 |
| 账户等级 | 无区分 | 所有用户的模拟盘功能完全相同 |
| 充币 / 提币 | 不支持 | 资金为虚拟额度，不能转入转出 |

策略交易这一栏要多说一句。官方帮助页只笼统写「含有实盘的所有交易模式」，没有列具体策略名。第三方教程在 2025 年初的记录里列出的清单包括现货网格、合约网格、信号策略、合约马丁格尔、现货马丁格尔、无限网格、天地网格、定投策略、屯币宝、抄底宝、逃顶宝、套利下单、冰山策略、时间加权策略。这份清单不是官方发布，实际能开哪些策略，以你进入模拟盘后交易页显示的选项为准。

官方还单独说明了合约模拟盘的定位：「合约交易相对现货交易需要更多的交易经验和知识，欧易在 App 端与 Web 端皆有合约模拟盘交易，新手用户可以在模拟盘交易进行练习操作，熟悉之后再进行正式的合约交易。」

## 怎么进去：App 和网页端两套路径

App 端有两条路能进，任选一条：

1. 打开欧易 App 并登录，点首页左上角图标进入个人中心，选【模拟交易】。
2. 点首页左上角的【九宫格】图标，直接选【模拟交易】。

进去后页面会显示总资产估值、币种列表和公告，点下方【交易】按钮选择交易产品和类型。

网页端只有一条路：登录欧易官网，点【交易】，在下滑菜单里选【模拟交易】。进去后左上角会显示【模拟盘交易】标志，用来和实盘区分。

以练 BTCUSDT 永续为例，两端操作一致：点交易页左上角币对框【BTC/USDT】，点转换按钮切换交易模式，依次选【永续】、【USDT 合约】、【BTCUSDT 永续】，然后在交易页选【买入开多】或【卖出开空】。

想回实盘，App 端点模拟交易旁边的【退出】，合约页右上方也有【返回实盘】。网页端要自己在页面上找【实盘交易】或【切换至实盘交易】按钮。官方两份帮助文档对网页端这个按钮的描述不一致，一份写的是页面右上角，另一份写的是页面下方，应该是界面改版留下的差异。按文字找，别记位置。

## 钱亏完了怎么重置：先平仓撤单，再点重置

这是多数教程漏掉的一步。官方在合约模拟盘的帮助页里写得很明确：「您需要取消所有挂单并关闭所有仓位，才能重置模拟资产。」另一处表述是「当交易完成后不存在挂单或持仓时，即可在模拟交易资产页面中，点击资产页【重置】按钮」。

有挂单或有持仓的时候，重置按钮不会按你的预期工作。先把所有委托撤掉，再把仓位平掉，账户干净了才能重置。

重置路径分两端：

**App 端**：打开模拟盘，点【总资产估值】，再点【重置】。也可以从【资产】页面找重置按钮。

**网页端**：点右上方的【资产管理 - 模拟交易】→【我的资产】→【资产】，点币种右侧的【...】，选【重置】。

模拟盘资金用完可以反复重置，恢复成初始的币种和金额，整个过程不涉及任何真实资金。

## 模拟盘和实盘到底差在哪

这一节是前排文章几乎都跳过的地方，因为官方自己的表述就有两处需要分开看。

官方帮助页（更新于 2026 年 11 月 10 日）的正文写得很直接：「模拟盘与实盘没有任何关联，行情不能互作参考，模拟盘的行情波动也与实盘交易没有任何关系。交易的结果也不会对真实的资产造成任何影响。」

同一页的 FAQ 里又有另一句：「模拟交易环境通过使用实时市场数据和交易工具来模拟真实市场环境，使交易者能够在不承担任何实际风险的情况下，体验数字资产市场的涨跌起伏。」

第三方开发者文档（GitHub 上的一个开源交易项目）在常见问题里给出的说法是：「市场数据相同，但订单成交可能略有差异。」

三处说法并列放在这里，能确定的只有两件事。第一，模拟盘的盈亏绝对不会串到你的实盘账户，交易结果不影响真实资产。第二，模拟环境用实时行情数据搭建，但成交价和滑点不要当成实盘回测的精确结果。至于「行情能不能互作参考」，官方正文说不相关，FAQ 说用实时数据，中间的分寸自己拿捏，别拿模拟盘的成交价去推算实盘能吃到什么价。

## 哪些事模拟盘干不了

这四条直接影响「能不能把它当正式环境用」的判断。

**不能开子账户。** 官方原文：「模拟交易不支持创建或管理子账户。模拟环境仅用于使用虚拟数字资产进行交易练习。子账户功能仅适用于真实账户，模拟模式下不可使用。」需要多账户隔离的团队结构，模拟盘给不了。

**没有账户等级。** 官方明确「模拟盘暂无等级区分，所有用户的模拟盘功能均相同」。实盘里那些跟等级挂钩的权益，在模拟盘不存在。

**不能充币提币。** 第三方开发者文档把提币、充值列为模拟盘不支持的功能，创建模拟盘 API Key 时提现权限也是不可选的。虚拟资金只在这个环境内循环。

**币对不全。** 官方说明模拟盘「主要是一些常用的交易币对以及部分热度较高的币对，满足您对交易币种的基础需要」。冷门币种在模拟盘里可能根本找不到，想测长尾标的的策略会受限。

还有一条需要标注来源：有第三方教程称使用模拟交易需要注册账号并完成身份认证（KYC）。官方帮助页没有提到 KYC 要求，这一点按第三方说法处理，注册流程走到哪一步以页面提示为准。

## 想接 API 或跑策略的人看这段

模拟盘支持 API 接入，但它和实盘是两套独立的凭证体系，混用会直接报错。

创建模拟盘 API Key 的路径是：登录账号，进【交易】→【模拟交易】→【个人中心】→【创建模拟账户 API key】。必须用 Demo Trading 环境下创建的 Key，并且开通交易权限。每个模拟交易请求都要加上请求头 `x-simulated-trading: 1`，同时使用所在站点对应的正确 API 域名。

几个容易踩的点：

- 报错 **50123** 表示该 API Key 没有数字货币交易权限，回去把交易权限勾上。
- 只有读取权限的 Key 能查账户数据，但下不了单。
- 模拟盘的 Key 不要去请求实盘接口，反之亦然。

有开源项目给出的工程做法是配两套 Key，一套实盘一套模拟，在 `.env` 里放一个 `OKX_TESTNET` 布尔开关，切换环境只改这个值，不用改代码。这个做法来自第三方项目文档，不是官方规范，但思路可以参考。

第三方文档还给了一条节奏建议：先在模拟盘跑至少一到两周，验证下单流程、止损止盈逻辑和持仓管理，再上实盘，实盘从 100 到 1000 USDT 的小资金起步。这套建议没有官方背书，但对第一次接 API 的人是合理的保守做法。
